A Python-based server monitoring system that collects CPU, memory, and disk utilization, stores monitoring metrics in PostgreSQL, generates daily Excel reports, and provides configurable threshold-based alerts.

Features

## Features


- CPU monitoring
- Memory monitoring
- Disk utilization monitoring
- PostgreSQL data storage
- Daily Excel report generation
- Configurable monitoring interval
- CPU threshold alerts
- Memory threshold alerts
- Disk threshold alerts
- Webhook notification support
- Alert cooldown mechanism
- Continuous monitoring
- Terminal status display
